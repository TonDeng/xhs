# 公众号运营方案 · 每天一个测试（完全免费）

> 目标：公众号每天推送一个不同类型的测试题（心理/性格/情感/趣味……），
> 测试与报告完全免费，靠内容留存和分享涨粉。
> 启动门槛：个人订阅号（免费注册）+ GitHub Pages 静态托管。

---

## 一、账号定位

**一句话定位**：每天一个不同类型的测试题，全部免费开测，测完即出完整报告。

- **内容形式**：每日一测（图文）+ 每周合集（长文）
- **测试产品**：多题库滚动推送。首发《七宗罪 × 七美德 · 人格光影测试》46 题，
  已上线题库：七宗罪 2.0 / SBTI 抽象人格 / 依恋类型 / 消费人格，
  后续扩展：MBTI 简化版 / 沟通风格 / 压力指数 / 趣味问答等
- **模式**：完全免费（测试 + 报告），无收费环节
- **昵称/头像/简介**：见 `product/商品上架资料.md`（推荐昵称「每天一个测试」）

## 三、增长与裂变

1. **朋友圈裂变**：测试结果页引导「分享你的主罪主德到朋友圈」——结果卡自带公众号水印
2. **关注转化**：推文首图 + 文末固定引导「关注公众号，每天一道免费测试题」
3. **话题互动**：文末提问「你的选择是？评论区扣字母」，评论区运营提升互动率
4. **菜单承接**：「免费测试」菜单直达测试页
5. **关键词自动回复**：回复「测试」→ 自动发送测试链接

## 四、转化漏斗（免费模式）

```
公众号推文（每日一测）
  → 点击测试页（免费做题）
    → 完整报告直接展示（免费）
      → 分享给朋友 / 关注公众号 / 明天再来测
```

**优化点**：
- 报告页内容足够好，让用户愿意分享
- 结果页引导「分享给朋友一起测」提升裂变
- 每日更新保持用户回访

## 五、执行节奏（冷启动 30 天）

| 阶段 | 时间 | 动作 |
|------|------|------|
| 准备期 | D1-3 | 注册公众号、部署测试页、配置定时任务、准备题库 |

## 六、KPI

- 日更率：≥ 5 篇/周
- 测试页转化：推文 → 测试 10%+
- 分享率：测试完成 → 分享 5%+
- 涨粉：冷启动 30 天目标 500~1000 粉（可配合小红书/抖音引流）
